# สวัสดีค่ะ ฉันชื่อ ฐณิชาฌ์ ลวัณยาภรณ์

**3D Character Artist / Character Concept Artist**  
กำลังสนใจเรื่องการปั้นโมเดลตัวละคร เพื่อนำมาต่อยอดจากผลงานวาดภาพสองมิติให้ดูสมจริงยิ่งขึ้น โดยมีความเชี่ยวชาญในการวาดตัวละครในลายเส้นกึ่งสมจริง และมีความรู้พื้นฐานในการปั้นโมเดลและใช้งานโปรแกรมเบื้องต้น

### 🎨 เกี่ยวกับฉัน (About Me)

-  **กำลังทำโปรเจกต์:** ปั้นโมเดล 3D ตัวละครพระเอกจากนิยายจีน "หวังหลิน" (Wang Lin)
-  **กำลังเรียนรู้:** การใช้งานโปรแกรม Nomad Sculpt และ Blender
-  **พูดคุยแลกเปลี่ยนกันได้เรื่อง:** การปั้นโมเดลตัวละคร (Character Sculpting) และเทคนิคการวาดภาพแนวเซมิเรียล (Semi-Realism)
-  **ช่องทางติดต่อ:** thanicha.l@ku.th
